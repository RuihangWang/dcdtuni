# Single-rack liquid control demo

Derived from the existing LiquidSingle geometry without changing the original. This is a generic mock liquid-to-liquid system, not the supplied liquid-to-air CDU70 or an NV-calibrated installation.

Open LiquidSingle_Control.cfdproj in React, switch the top bar to liquid mode and open the liquid solve tab. The embedded case path is intentionally empty for portability: select this case directory on the server.

How it runs as of 2026-10-22: the project carries no saved experiment, so the editor uses the differentiable Newton DAE. The readiness checklist should read all-pass; **Solve steady state** (steady) or **Initialise and run** (transient) exports the network and runs it, saving synthetic primary-side assumptions (1 kg/s at 20 °C, 0.02 m³ on each HX side, the project fluid's cp/rho, mock equipment curves); they are numerical assumptions, not measurements. Set the liquid domain to transient in the top bar, then use a 180 s horizon and a 1 s step, and optionally tick the cold-plate load step to multiply all cold-plate heat inputs by 1.5 at 60 s. Inputs follow manual schedules (there is no closed-loop controller in this mode); compare the cold-plate temperature response with and without the load step, or across pump settings. No saving/energy performance claim is implied.

The cold-plate temperature PI controller shown in earlier versions of this demo belongs to the legacy v2 experiment: it is available only in a project that already saved an explicit v2 experiment, and the Newton DAE accepts manual schedules only. Next step for a PI comparison: add a closed-loop controller to the DAE experiment, or save a v2 experiment in a copy of this project and run it through the legacy-compatibility button.

Mock cold plate: 3500 W baseline, UA 300 W/K, solid heat capacity 8000 J/K, coolant volume 200 mL, pressure drop 10 kPa at 4 L/min. The current thermal kernel resolves solid/pipe storage but not separate cold-plate fluid storage. Facility reservoir: 20 °C; fluid rho 997 kg/m³, cp 4182 J/(kg·K), viscosity 0.00089 Pa·s, conductivity 0.606 W/(m·K). Pump/HX/valve use versioned mock-demo-v1 profiles in the dynamic graph compiler. Replace these fields and the pack with measured equipment specifications before calibration.

Results: the liquid results tab shows the network (actual flow direction, flow, velocity, pressure drop), heat and the HX, per-object curves of a transient, and the solver laws the run used. Its 3D display colours the loop by temperature, flow, velocity or pressure and draws flow arrows in the actual flow direction, coloured by velocity: here the DN100 headers carry the same mass flow as the DN25 rack branch at a sixteenth of its speed. Checked end to end in the browser on 2026-10-22 (steady solve converged, about 8.3 L/min through the cold plate).
