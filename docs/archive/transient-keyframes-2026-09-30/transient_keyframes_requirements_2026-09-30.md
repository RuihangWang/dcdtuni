## 1. 用户原始要求（要义逐条，按原意保留）

1. **模拟类型在顶边栏选择**：稳态 / 瞬态。
   - 稳态：风冷、液冷都**不出现**进度条。
   - 瞬态：顶边栏下方出现一条"**进度条 + 关键帧**"（类似视频编辑时间轴）。
2. **进度条要素**
   - 用户可在进度条上**添加关键帧 marker**；关键帧滑块可任意拖动，也可**精确输入时间**。
   - 进度条**最右端**设置**模拟时长**。
   - 进度条**最左端**设置"**起点**"：可选"**稳态收敛场**"或"**均匀初始场**"等。选稳态收敛场时，**先算稳态，再从该场开始跑瞬态**。
   - 起点与终点位置都可以放 marker。
3. **关键帧的语义**：每个关键帧 = "**当前全场所有边栏（属性）的一个 snapshot 状态**"。
   - 起始 marker 若是稳态模拟，则此时在"几何与属性"tab 里设置的就是稳态模拟的参数。
   - 滑块移动到某个已有 marker 时，用户可在"几何与属性"tab 修改**任意组件的性能参数**，该修改记入这个 marker 的 snapshot。
   - **暂不支持改变几何**（以后可以支持）。
   - 可变的例子——**风冷**：patch 内的边界条件，如 server 功率、ACU 送风温度、ACU 风速（可设为 0/关闭）、送风角度等；
     **液冷**：某些端点的边界条件，如供水温度、温升、压降/流量等。
4. **瞬态必须"编译"**
   - 风冷：编译成 **OpenFOAM 能识别的时变边界条件**。
   - 液冷：编译成**我们的 DAE 求解器能识别的版本**。
5. **文件格式版本**：上述改动进入新的 **`cfdproj_V5`**、**`cfdrun_V3`**、**`liquidrun_V2`** 设计流程（用户强调"这个很关键"）；
   **以前默认稳态的风冷 `.cfdproj` 必须继续兼容**。
6. 这些要求要放入 DCtwin 相关的主线开发要求里（本文件 + MAINLINES §2 + 仓库开发文档）。

## 1b. 用户裁决（2026-09-30 SGT，同一会话）

- **关键帧之间为阶跃（跳变）**：边界条件保持到下一关键帧时刻再整体切换，不做线性渐变。
  OpenFOAM 侧用 `table` 阶跃语义（`uniformFixedValue`/`uniformInletOutlet` 的 `outOfBounds clamp` + 相邻两点同一时刻跳变，或 `interpolationScheme step`），
  液冷 DAE 侧为分段常数输入。
- **液冷格式版本 = `.liquidrun` v4**：用户所说的 `liquidrun_V2` 即现行严格 v3 之后的下一版，正式命名为 **v4**
  （`cfdproj_V5`、`cfdrun_V3` 维持用户原命名）；v3 文件继续可读（稳态/无关键帧）。
