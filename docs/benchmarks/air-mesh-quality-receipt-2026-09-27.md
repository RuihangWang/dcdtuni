`air-mesh-quality/v1` binds an explicit strict `checkMesh` verdict to the exact five-file serial or complete partitioned `polyMesh` identity and the selected `.cfdrun` bytes. It records `accepted` only for an explicit `Mesh OK.` with process exit 0 and unchanged mesh bytes; `Failed N mesh checks.` becomes `rejected` even when OpenFOAM exits 0. Missing verdict, process failure, or mesh mutation writes no receipt and revokes any earlier accepted receipt. The verifier rehashes the current mesh and `.cfdrun` before returning the saved verdict. A copied JSON file alone does not prove that `checkMesh` ran; an accepted OV result additionally needs final patch lineage, field dimensions, and an output-run receipt.
