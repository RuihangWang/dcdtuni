# Exact physical-facet coalescence proposal

This is an unbuilt, default-OFF source proposal. It extends the bounded two-tetrahedron literal union only when its six-facet shell fails the stock face-centre geometry predicate. It may cancel one shared diagonal between exactly two physical triangles with the same actual patch, zone and original source-face identity. All four original nodes must remain on an exactly identical binary coordinate-axis plane and form a strictly convex outline. Rotated and warped outlines remain unsupported.

The current immutable CUA case supplies the positive offline oracle: cells 526915/526916 and physical faces 1929288/1929289, original source parent 30430 and source face 1959121. The complete 178-cell stencil and independent full union result are archived here. This candidate preserves all 176 other complete cells' centres and volumes. Its local determinant/weight/volume-ratio/skew/non-orthogonality are 0.148759458/0.085089141/0.034285714/0.248344012/49.246823 degrees. These are offline candidate results, not a native full-checkMesh pass.

The separate standard-library Fraction oracle derives exact signed area and first moment from the original binary outline. Fifteen tests reject mismatched original patch/zone/source-face or outside roles, one-ULP warp, unsupported rotated plane, concavity, retained collinear/duplicate vertices, invalid shared-edge orientation and non-finite coordinates. They also check coordinate-cycle rotation and reversal. Complete cell quality and every original passing-role inheritance are verified by the previously independent small-union audit, reproduced independently by the root from the same current stencil.

Normal source-face metadata is allocated only when the new opt-in flag is enabled and is maintained independently of optional trace output. Both deleted physical face roles map independently to the surviving quad's quality; a lower numeric face label cannot erase another original passing role. The pair budget and two rounds are unchanged. The source hash, incremental patch and source-bound test output are recorded in `source-test-identity.json`. No service, native binary, case or source geometry was changed by these offline tests.
