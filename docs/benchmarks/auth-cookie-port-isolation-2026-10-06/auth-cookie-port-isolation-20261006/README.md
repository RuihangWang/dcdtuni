# HTTP-port cookie isolation (IT source; live verification pending)

The fixed stlgen_session cookie collided across the same host's ports. Both servers issue a host-only Path=/ cookie, while their own AuthManagers contain different session stores. Source and actual process/store configuration prove the mechanism; no browser cookie values or live tokens were read/copied.

The IT-only change namespaces cookies as stlgen_session_<bound HTTP listener port>, taken from handler.server.server_address, never Host. Login flags and 12-hour lifetime are unchanged. A present scoped token cannot downgrade to legacy; only an absent scoped name can use a legacy token that validates in the same AuthManager. Successful scoped login clears a legacy browser cookie only when it is owned by that manager, preventing resurrection after scoped logout. Logout revokes its chosen session, clears only its namespace, and expires legacy only when legacy was chosen. Foreign-port sessions/cookies remain untouched.

The internal fake-browser regression confirms HTTP8396 cookie naming with WS8397 configured. The current terminal authenticates a query token against its process AuthManager, not cookies; that entire WS function, startup sockets and routing AST are unchanged. Frontend auth/TerminalPanel and AuthManager are byte-identical to MAIN. No auth-disabled mode, shared session store, session copying, Host-based namespace, or broader loopback bypass was added.

Red baseline: 10 failures / 1 pass. Final: all 36 cases pass, comprising 11 focused cookie cases and 25 existing browser lifecycle cases. The in-memory CookieJar accurately models one same-host jar receiving cookies from two fake handler ports; no HTTP was sent. The initial test-import authoring error is retained separately and was corrected before the meaningful baseline. Test TMPDIR/TMP/TEMP, pytest basetemp and cache are all within this owned repo directory, CPU36–39/CUDA empty.

Only production server.py and the new focused test file changed. Server-before/after, narrow diff, exact command receipts, original logs and source hashes are bound by manifest.json. Tmp and pytest cache directories are excluded from the publication payload. Actual browser login/Load/logout acceptance after a normal owned IT restart remains for ROOT; neither running MAIN nor IT was restarted here. Port-named cookies fix accidental overwrite, but do not make same-host ports independent browser security principals.
