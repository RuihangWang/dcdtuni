# Base604 网格下界：对比判据（先登记，后求解）

登记时间：2026-10-26，在 B、C 两套网格求解之前。

**网格。** 均为 dcCart，除下列两项外与 `case/Base604/Base604.cfdproj` 的网格设置相同（`maxGlobalCells` 临时设为 8,000,000，仅为本机内存检查，不截断细化）：

| 名称 | `meshBaseSize` | `rackRegionLevel` | 机柜区单元 |
|---|---:|---:|---:|
| A（现行） | 0.25 m | 3 | 31.25 mm |
| B | 0.20 m | 2 | 50 mm（≈ 1U，6Sigma 机柜节距） |
| C | 0.25 m | 2 | 62.5 mm |

A 在本机（15 GB）出不了网格：细化后 1,080 万个八叉树单元，需约 13 GB 加 4 GB 余量。A 与 B 的对比要在内存足够的机器上完成，命令见 README。

**求解。** 同一稳态设置（工程自带的 `fast` 预设与一阶格式），经脚本化 API，4 个 rank，按产品稳态判据（回风温度先变后平，0.5 K）停算。

**判据（C 相对于 B）。** 全部满足才算 C 与 B 一致：

1. B、C 都得到 `CONVERGED`。
2. 每个 ACU 回风温度之差 ≤ 0.5 K。
3. 各机柜进风温度（API 的 `rackInlet`，按机柜）之差：平均绝对差 ≤ 0.5 K，95 % 分位 ≤ 1.0 K，最大 ≤ 2.0 K。
4. 两者的热量账本（ACU 移热对申报 IT 功率）相对差都在 1 % 以内。

同时如实记录单元数、出网格时间、每步时间、收敛步数与总求解时间。结果写在 README.md，判据不改。
