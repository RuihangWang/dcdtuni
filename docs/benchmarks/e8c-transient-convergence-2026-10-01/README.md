## 松弛研究(记录在设计 §E8c)

外迭代沿用工程的松弛(与稳态共用 p_rgh 0.3 / 方程 0.7)。固定 0.01 s 步长(库朗数 23)时每步都触顶;自适应 maxCo 5 时每步 15–17 次收敛。
p_rgh 0.5 / 0.7 的更激进组合每步只需 9–10 次但运行发散(Δt 塌到 1e-9 s),0.7 / 0.9 同样发散。结论:保留稳定的共用松弛、默认阈值
p_rgh 1e-3 / 其余 1e-4、每步上限 20;时间步过粗的运行会在判定里表现为大量触顶步。代价:每步约 16 次外迭代,约为旧固定 2 次的 8 倍。
