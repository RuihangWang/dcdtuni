# test_thermal（Adam ODIL 研究基线）的收敛判据（先登记，后运行）

登记时间：2026-10-26，在下述三个起点运行之前。

**背景。** 单次运行“最终损失 < 1.0”不可复现：从 GGA 水力解出发、对流量加 ±1e-11 kg/s 量级的扰动，lr=1.0 时 5 次中 4 次落在 0.23–0.35、1 次落在 4.55；lr=0.1、0.01 在 15000 步内都不收敛（最终损失 3–6000）。这是 Adam 优化路径对舍入级扰动敏感，属研究基线方法的性质；生产路径是 Newton DAE。上述扫描已经看过，所以判据只用于下面一组**新的**起点。

**判据。** `thermal_loop.liquidrun`，lr=1.0，max_epochs=15000，从 GGA 水力解出发，对所有流量加 ε ∈ {−3e-11, +3e-11, +5e-11} kg/s 三个起点；**三次最终损失的中位数 < 1.0** 即通过。其余物理检查（流量一致、方向、芯片温度范围）对中位数那一次运行检查，界限不变。

**结果。** 运行后写在 README.md，判据不改。
