# OV 显示（液冷 + 风冷）回执（2026-10-01）

**结论：过门。** 在修完 OV 切换（`ov-switch-fix-2026-10-01`）之后，按用户要求验液冷、风冷两条 OV 显示链路，途中又发现并修复两处缺陷：

1. **OV 结果数据集列表不跟随工程**（`f898a370`）：面板只在挂载时列一次运行；OV 打开期间换工程或求解完成，列表停在「当前工程 log/ 下没有已求解的运行」，风冷结果无法载入 OV。现在列表按会话里的 case 目录与已求解运行名重新拉取。
2. **分区运行无法进 OV**（`3a817a72`）：dcCart 默认 8 核网格 + 8 核求解、不重构，运行目录只有 `processor*/`；OV 转换器只认串行运行，回 409 `run_decomposed`——**默认流程下的风冷结果从来进不了 OV**。现在分区运行按处理器建镜像（各自 constant/ 与最新时刻场的符号链接），签名覆盖每个处理器的网格与场，用 `mpirun -np N foamToEnsight -parallel` 写出与串行相同的单个 EnSight case；最新时刻须在每个处理器上都有场。
