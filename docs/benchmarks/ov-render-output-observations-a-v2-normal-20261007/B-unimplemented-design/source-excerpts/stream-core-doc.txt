9: ## Architecture
10: 
11: The `omni.kit.livestream.core` extension is built around a server factory pattern, consisting of:
12: 
13: - **IServerFactory Interface**: Provides methods to register, deregister, and create streaming server instances based on type.
14: - **ServerFactory Implementation**: Implements the factory interface to manage registration of different server types and create instances on demand.
15: - **IServer Interface**: Defines the common interface that all streaming server implementations must follow, enabling consistent handling regardless of the underlying streaming technology.

63: ## Integration with Other Extensions
64: 
65: The `omni.kit.livestream.core` extension integrates with:
66: 
67: - **omni.kit.livestream.webrtc**: Provides WebRTC and native streaming implementations.
68: - **omni.kit.livestream.app**: Handles streaming the entire application framebuffer.
69: - **omni.kit.livestream.aov**: Handles streaming specific render product AOVs.
70: - **omni.kit.livestream.messaging**: Enables structured messaging between server and clients.
71: - **omni.services.livestream.session**: Manages livestream sessions and provides control endpoints.
