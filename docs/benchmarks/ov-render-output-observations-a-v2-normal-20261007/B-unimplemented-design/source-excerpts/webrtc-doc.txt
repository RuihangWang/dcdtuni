LINES 3–12
3: The `omni.kit.livestream.webrtc` extension provides implementations of the streaming server interface (`IServer`) for both WebRTC and native protocols. It enables streaming video frames from CUDA buffers to remote clients with support for bidirectional messaging and input handling.
4: 
5: ## Purpose
6: 
7: This extension bridges the Omniverse Kit rendering pipeline with remote clients by:
8: 
9: 1. Registering WebRTC and native streaming implementations with the `omni.kit.livestream.core` server factory
10: 2. Providing efficient CUDA-based video frame encoding and streaming
11: 3. Handling client input and message events
12: 4. Managing streaming sessions and connection state

92: ### Stream Types
93: 
94: The server manages three types of streams:
95: 
96: 1. **Video Stream**: For streaming video frames from CUDA buffers
97: 2. **Audio Stream**: For streaming audio data (when enabled)
98: 3. **Input Stream**: For receiving input events from the client
99: 
100: ### Resizing Capabilities
101: 
102: The server supports two types of resizing:
103: 
104: - **Static Resizing**: Before client connection (via `resizeVideoStreamStatic`)
105: - **Dynamic Resizing**: After client connection (via `resizeVideoStreamDynamic`)
