# Shared React / OV postprocess previews: source and CPU checkpoint

The common React postprocess driver now converts its selected slice ring and streamline seed sphere into an owned public Kit SceneView. It returns only final handle positions to the same common form. The numeric product, selected run/frame and every computed slice/trace list entry remain owned by the existing shared driver and signed renderer grant.

The preview binding checks source, packet hash, time, acknowledged scene revision, display generation, scope, exact set ID, adapter owner and native lease/sequence. Replacement, clear and retirement fence late ACKs/events. Native drag cancellation restores the original shape without a readback event; the existing source-object edit channel remains separate.
