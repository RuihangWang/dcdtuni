# Browser panel resizing

Root exercised the main React production build through the Windows Codex in-app browser at its natural 1520 × 956 viewport. Arrow-key changes, the Shift increment, left/right panel collapse, toolbar collapse, manual-size restoration and inverse key changes all matched rendered DOM dimensions and ARIA values. Hidden splitters leave the tab sequence, the focused log splitter has a visible outline, and every captured step has no horizontal overflow.

The receipt is a compact transcription of the CUA measurements. The original full-view native screenshot was taken after sizes were returned; it is not a screenshot of every intermediate action. Real max/min traversal was not tested in this browser receipt. Earlier component tests and build evidence remain separate. Navigation later recreated the natural adaptive toolbar layout; no inline CSS was written through browser evaluation.
