# Independent mixed cone / face-fan diagnostic audit

This audit reads the unchanged 54-cell Cartesian transition, its 270-cell mixed subdivision and the original stock OF2412 two-process checker artifacts. It performs no native execution and changes no point, mesh, C++ source, binary, checker threshold or source STL. The existing diagnostic passes full checkMesh; it is not a user-case mesh acceptance.

All 130 original point coordinates remain bit-identical at their original IDs. The output has 163 points: 24 face centres and nine parent apices are added. Nine original coarse cells become 225 children, with 45 other cells retained. The written checker confirms 45 hexahedra, 45 pyramids and 180 tetrahedra. Independent signed-pyramid volume reconstruction gives minimum child volume 0.020833333333333332 cubic metres and total volume 22.499999999999986 cubic metres. Per-parent conservation differs by at most 2.220446049250313e-16 relatively.

Each of the nine apices is its recorded original OF cell centre and lies at least 0.49999999999999994 m inside every original outward face halfspace. Every original retained vertex satisfies the base halfspaces. For this convex closed fixture, any ray from the apex reaches one original boundary point. Coning a complete base partition therefore partitions the parent without overlaps except shared boundaries. This argument requires a closed, non-self-intersecting original surface and a strict kernel apex; a centroid alone is not a general interior guarantee.

The 24 fan bases have strictly positive triangle areas, at least 0.125 square metres. Each retained original boundary edge appears exactly once. Summed oriented and unsigned fan area equals the original base area, with zero recorded relative difference. All added face-centre bits reconstruct from the same coordinate-canonical polygon arithmetic. Each boundary output piece is independently contained in exactly one original parent boundary polygon, and all original polygon areas are covered with zero relative area difference. The single walls patch changes from 93 to 141 faces while its area remains exactly 48 square metres. This proof covers this one-patch fixture, not arbitrary production patch and zone labels.

The original raw checker log has nProcs=2 and flags -allTopology -allGeometry. It reports Mesh OK, all topology/geometry checks passed, minimum determinant 0.0289411, minimum interpolation weight 0.2, minimum volume ratio 0.166667 and total volume 22.5. All 30 files named in the original native receipt were independently re-hashed and match. The construction occurred globally before stock decomposePar: the resulting processor interfaces are covered, while independent per-rank fan construction and cyclic transforms are not.

Coordinate-canonical cycles give the same centre bits for cycle rotations, reversal and local label permutations when their input coordinate bits agree. Triangle ordinal is a separate matter. Actual original face4 has common edge order [01,12,23,34,04]. Reversing the whole cycle to match opposite outward normals changes that order to [34,23,12,01,04]. The unordered edge key sets agree, but identical local ordinals refer to different triangles. The global prototype creates each face partition once and reverses each neighbour triangle individually. A distributed implementation must preserve a common triangle identity/order before changing triangle orientation; common unordered edge keys provide such identities.

A 90-degree rotation of that same face changes the coordinate-canonical start from [0,1,2,3,4] to [1,2,3,4,0]. Rotational cyclic pairs therefore require a common transformed coordinate frame or verified vertex correspondence; local lexicographic geometry order is insufficient. Coincident exact-coordinate matching does not itself prove original coupled patch-pair identity. AMI, mapped and unsupported transformed couplings remain outside this diagnostic.

A further mathematical counterexample records why proper-edge-crossing checks alone do not establish that a concave original-vertex fan is nonoverlapping. The planar polygon [(0,0),(1,0),(-1,1),(-1,-1),(2,0),(-2,2)] has no proper crossings, but its third point lies inside the nonadjacent closing edge. The original-vertex fan has positive areas [0.5,1,1,2], summed area 4.5 and an OF centroid difference of only 4.16e-17 m. Nevertheless, its first triangle lies entirely inside the last. A valid simple-polygon gate must also reject nonadjacent vertex/edge touches and collinear overlaps. This is a base-only counterexample; it does not claim that a complete native cell would pass every other guard. The native owner has added the stronger intersection gate after this review.

Four focused mathematical tests pass. The native experimental stage must still pass actual coupled closure, geometry, physical boundary/zone preservation and the full timed product pipeline before it can authorize a production mesh.
