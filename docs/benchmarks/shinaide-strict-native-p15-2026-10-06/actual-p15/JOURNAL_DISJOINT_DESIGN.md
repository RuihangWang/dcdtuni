# Bounded legacy journal: source-only next-step proposal

This design is NOT implemented or experimentally accepted. P15 proves only the first refusal at `dcCartCompleteCavityLocalOracle.H:565`:10 views with local legacyAccepted nonzero. It does not prove disjointness, later current predicates, geometry quality, or a potential successful repair.

## Exact insertion and ownership

The normal old-union commit is in frozen `dcCartCutCells.C:14812–14842`, after complete geometry/role preflight. Line14826 joins source provenance; line14827 removes the shared facet/drop cell and updates cell-face incidence; optional physical coalescence14828–14832 removes another facet; lines14834–14841 change owner/neighbour/raw ring and cached area/centre/CC/V/D. Line14842 increments the non-packet `accepted` counter. At14979 that count is passed unchanged to `current` and `apply`.

A future normal owned journal would capture immutable before/after dependency records for EVERY successful non-packet commit at this existing commit boundary. Record both cells, removed/replaced facets, all current core/outside/second-halo cells and their raw facets needed by cached CC/V/quality, raw owner/neighbour and point0-preserving ring, patch/zone/physical role, every touched native point and alias representative/membership, and complete source-origin lineage. Preserve original IDs and source fingerprint; do not recapture the earliest oracle as a new baseline. Existing optional evidence JSONL14844–14858 supplies keep/drop/deleted/exterior IDs and quality observations, but does not supply a complete mutation/dependency/alias certificate and cannot authorize reuse.

## Permission and required negative behavior

Journal completeness must agree with the full local non-packet accepted count. Missing entries, count mismatch, unknown source/role, exception, payload/cap/clock exhaustion, or unsupported mutation conservatively leave the existing legacy refusal. No silent truncation, partial journal, count reset, clearing stale state, or deletion of old gates is allowed. Journal allocation failures affect only the new complete-cavity permission, never the accepted old-union behavior.

Only a completely described journal can support a narrow per-View disjointness proof. Require no intersection of journal changed/dependent cell, facet, point/alias, or source-origin sets with the full captured View dependency closure. Existing W committed packets remain separately protected; their state cannot be cleared or treated as old literal entries. Global alias/active-point identity is still required: current H578–592 directly checks entire earliest/live active membership and H593–596 checks every native point's bits. A spatially distant journal entry does NOT waive these checks. If any legacy deletion changes global active point membership, disjointness alone is insufficient and this first design must refuse.

All existing checks after the legacy predicate remain in their original order and strength: budget/rank/checkpoint, full active/native point payload, W packet overlap598–607, captured cell incidence/raw facet ownership/ring/role608–626, and sourceFingerprint+completeOrigins627–638. No geometry result may be reused across a dependency change. Admission does not replace current/prefix/final installed quality and mandatory earliest coupled DP certificates. Existing normal all-rank control flow and writer-before-Fatal gates remain unchanged.

## Bounded cost and test plan

Use explicit per-rank entry and byte caps, never an unbounded whole-case history. Reuse current permission bounds (core128/outside256/secondHalo512/faces2048/points8192/aliasMembers8192/payload16MiB; normal index64MiB) for each complete closure, and a separately reviewed finite journal-entry cap. Overflow disables new permission without affecting old literal commits. P15 has no serialized Views/journal, so its required byte count and overlap cost cannot currently be measured. Current H active/full-point scans are already bounded by authority checks every256 items; optimizing them into cached epoch values is a separate proof obligation, not part of this proposal. No assertion is made that 300 s or the cavity-stage budget will permit a candidate.

Required future meaningful tests: empty journal with zero legacy retains existing behavior; nonzero legacy with missing/partial/count-mismatched/overflow/expired journal refuses; overlap of cells, cached outside/second-halo facets, physical role, native point, alias member, or source origin refuses; exception keeps false. A complete truly disjoint record may get past ONLY the new journal permission while unchanged later predicates are still evaluated; altered global active membership, point bits, raw cell ring, role, fingerprint, prior W packet overlap, or final quality/coupled evidence still refuse. Actual native acceptance requires new normal React evidence; no tests or implementation are executed in this audit.
