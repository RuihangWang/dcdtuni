## Key book features
- Reader-centric approach to scientific writing
- Original tools for assessing fluidity and readability
- Covers: titles, abstracts, introductions, body, conclusions, references
- Module on "elementary principles of composition: clarity, conciseness, organisation, precision, fluidity"
- Detection of "structural problems at sentence, paragraph, and paper level"

## Seminar topics (from scientific-writing.com)
- Module 1: Structure (title, abstract, introduction, body, conclusion, references)
- Module 2: Composition principles (clarity, conciseness, organisation, precision, fluidity)
- Module 3: Detecting structural problems at sentence, paragraph, and paper level
