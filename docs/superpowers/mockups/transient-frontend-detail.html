关键交互说明

事件列表 ↔ 属性面板双向同步：

  • 在"添加事件"弹窗创建事件 → 自动写入 model.timeVarying → 属性面板 ⏱ 按钮变 ⏱✓
  • 在属性面板 ⏱ 编辑器修改数据 → 事件列表自动更新
  • 事件列表是 只读聚合视图，数据源始终是 model.timeVarying

"添加事件"弹窗是快捷入口：自动生成 time-value table（阶跃=两行相同值+一行目标值，爬坡=线性插值），写入 model.timeVarying。高级用户可在属性面板 ⏱ 编辑器里精细调整。
