瞬态模拟 UI 设计方案

如何让用户定义 Server 功耗变化 + ACU 状态变化的瞬态场景？

A

事件列表 + 内联时间线预览

左侧是事件列表（"t=60s ACU-1 关机"），右侧自动生成简化的时间线甘特图预览。用户通过"添加事件"按钮创建事件，每个事件选择设备、变化类型、触发时间。

优点

  • 事件驱动直觉，像故障报告
  • 时间线预览一目了然
  • 适合多数场景

缺点

  • 复杂功耗曲线（如日负载周期）不好表达
  • 需要额外的"编辑曲线"入口
B

设备属性面板 + 时变开关

在现有的右侧属性检查器中，每个 ACU/Server 的参数旁增加一个"⏱"按钮，点击后展开时变编辑器（表格或迷你曲线）。不需要单独的瞬态场景面板。

优点

  • 与现有 UI 无缝集成
  • 精确到每个参数
  • 可用于任意复杂曲线

缺点

  • 缺少全局视角（要逐个设备查看）
  • 不方便构建"故障场景"
C

A + B 混合：场景面板 + 属性内联（推荐）

新增一个"瞬态场景"左侧 Tab（和 geometry/mesh/solver 同级），提供事件列表 + 时间线预览（方案A）。同时在设备属性面板保留 ⏱ 按钮用于精细调节（方案B）。两处数据双向同步。
