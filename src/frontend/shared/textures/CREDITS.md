# Texture Credits

This folder is the one material and texture pool of the project. Its manifest,
`materials.json` (schema `src/frontend/shared/schema/material-library.schema.json`),
lists every image with its source, size, byte count and sha256 (= its Git LFS
oid), and every material the editors and Omniverse draw. Both editors, the
React -> Omniverse display bridge and the Kit-native `.cfdproj` path read that
file; nothing keeps a copy of its numbers.

## Sources

- **Generated sets** are project-owned and released CC0. `tools/gen_pbr_textures.py`
  rebuilds them from the recipe and seed in the manifest (numpy + Pillow,
  periodic FFT noise and periodic layouts, so every map tiles seamlessly);
  `--check` proves the repository copy is byte-identical.
- **Photo sets** are CC0 downloads, credited in the table below with their URL.
- **Single images** that a saved project names by URL (`/textures/electric-box/...`)
  or by patch preset id (`grilles/`) keep their paths so existing projects load.
  The grille presets and `panel_lamps.jpg` were added in 5868b463a (2026-09-09)
  without a recorded source: verify before redistributing them.

## Map conventions

- `color` sRGB. `containment-panel/color.png` carries alpha (opaque frame,
  translucent polycarbonate).
- `normal` tangent space, OpenGL convention (+Y green = up).
- `roughness` absolute roughness, read from the green channel; a renderer that
  binds it sets the scalar to wanted / `stats.meanRoughness`.
- Images are at most 1024 px on a side.
